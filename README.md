# Michigan Money Saver

**The classified board that gives the publish back to the everyday man.**

List free. Reach the board. The press belongs to the people.

## The doors

- [michiganmoneysaver.pro](https://michiganmoneysaver.pro)
- [michiganmoneysaver.shop](https://michiganmoneysaver.shop)

Both doors are live and secure. This repository is the board's home: its code is house property, built and deployed from here to GitHub Pages.

## What it is

Michigan Money Saver is a general classified board — list anything lawful, in plain language, without per-word tolls or an editor's desk standing between you and the public. It is home to the **Barter House**, and its traders' wing sails under the name **Pirate Traders Cove** — a clean, above-board cove for deal-shoppers.

The board is built and run by **Apex Air Solutions** of Johannesburg, Michigan, as part of a classified web: local boards built for local people, whose listings rise to this main board.

## The principle

Classified ads used to belong to the newspapers, priced by the word. This board exists to hand that power back: **list free, reach the main board, and let buyer and seller talk.** That is the whole model, stated in the open.
